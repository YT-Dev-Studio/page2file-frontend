# Page 2 PDF en-US outreach playbook

This file prepares outreach; it does not authorize automatic email, comments, directory submissions, or Reddit posts. Confirm the Chrome Web Store listing, production samples, contact identity, and each site's current rules before sending.

## Prioritization

1. Start with `very_high` editorial pages that already rank for the exact task and are actively maintained.
2. Then approach `high` comparison pages with the sample that matches their reader's problem.
3. Use broad productivity lists only after Page 2 PDF has real installs, ratings, and retention evidence.
4. Treat competitor listings and community threads marked `monitor` as research, not backlink targets.
5. Do not pay for inclusion unless sponsorship is clearly labeled and separately evaluated.

## Native Reddit post outline

- Title the actual problem, not the product: `I tested why Chrome Print clips internally scrolling pages`.
- First paragraph: disclose `I built Page 2 PDF`.
- Show the reproducible fixture, expected page count, and both outputs.
- Explain the tradeoff: visual fidelity versus selectable text and links.
- State unsupported cases and privacy boundary.
- Link to the sample before the Store listing only if subreddit rules allow it.
- Ask for failure cases, not upvotes or reviews.
- Never post the same copy across multiple communities.
