## Подготовьте видимые источники и медиа

Раскройте панели источников и ответы, которые должны войти в запись. Дождитесь изображений и загруженных медиа. В предпросмотр попадает только то, что доступно активной странице.

Видимая citation может остаться безопасной кликабельной ссылкой в редактируемом режиме. Проверьте совпадение области и подписи, а также работу адреса вне вашей сессии.

## Выберите читаемый формат

Accurate copy — режим точной визуальной копии сохраняет карточки, интервалы и изображения Gemini. Editable document — режим редактируемого документа переносит поддерживаемые текст, код, изображения и ссылки, используя скриншоты для сложных блоков.

Общая подготовка описана в [руководстве по приватности AI-чатов](/ru/blog/export-ai-chats-privately).

## Используйте Takeout для данных аккаунта

[Документация Google](https://support.google.com/gemini/answer/16920332?hl=en) объясняет выбор Gemini и Gemini Apps activity в Takeout и создание архива. Скачивание архива само по себе не удаляет данные с серверов Google.

Takeout нужен для широкого архива. Page 2 File — для одного проверенного разговора в PDF или PowerPoint.

## Проверьте приватность и независимость

Удалите персональные данные, конфиденциальные prompts и посторонние uploads. Проверяйте утверждения по исходным источникам.

Данные предпросмотра удаляются после закрытия вкладки; Page 2 File не ведёт базу истории. Page 2 File — независимый продукт и не является сервисом Google или Gemini.

## Задайте границы Gemini conversation

Проверьте Google account, особенно если в браузере открыто несколько profiles. Выберите видимый response path, первое и последнее сообщение. Уберите setup и поздние prompts, не относящиеся к документу.

Загрузите старые messages, sources, code и media. Если ранние turns исчезают после прокрутки, уменьшите диапазон. Сохраняйте prompt с важными constraints, иначе ответ легко неправильно прочитать вне интерфейса.

## Проверьте sources и generated media

Откройте source panels и протестируйте значимые links. Сохраняйте attribution, но проверяйте claims самостоятельно.

Generated images, maps и rich cards могут стать fallback-скриншотами. Если Google file или attachment только указан ссылкой, PDF беседы не содержит этот отдельный файл.

Запишите mode: editable помогает с supported text и links, Accurate copy сохраняет cards и layout.

## Защитите данные аккаунта

Проверьте profile names, email, workspace info, private prompts и side-panel history. Закройте preview после скачивания: временные данные удалятся, а Page 2 File не сохранит conversion history.

Назовите результат одной видимой беседой Gemini на дату. Google Takeout предназначен для более широких account data. Page 2 File независим от Google и не проверяет ответы Gemini.

## Сверьте sources, media и messages

Запишите первый и последний message, нужные source panels, generated images и контекст attachments. Сравните inventory с preview. Visible source label не является копией source, а thumbnail — исходным downloadable asset.

В Editable document найдите характерные phrases и проверьте важные links. В Accurate copy оцените grouping, мелкие citation labels и captions. Запишите hidden branches, unavailable media и unloaded history.

## Учитывайте alternative responses

Если Gemini показывает несколько drafts, выберите видимую версию и зафиксируйте выбор. Линейный PDF не должен создавать впечатление, что скрытые варианты существовали одновременно.

После скачивания проверьте boundaries, account details и нормальный zoom. Preview удаляется после закрытия вкладки, conversion history не хранится. Для широкого архива следуйте текущей документации Google Takeout.
