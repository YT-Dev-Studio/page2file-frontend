Чтобы экспортировать чат Claude в PDF, откройте нужный разговор в web-приложении Claude, загрузите весь диапазон и захватите активную вкладку через [расширение Page 2 File](/ru/chrome-extension/how-to-use). Предпросмотр показывает сообщения, код, источники и видимый контекст artifacts.

Page 2 File создаёт один читаемый документ из отрисованного содержимого. Он не просит пароль Claude и не заявляет доступ к скрытым разговорам.

## Загрузите длинные ответы и artifacts

Прокрутите к самому раннему нужному сообщению и дождитесь загрузки. Раскройте citations, код и содержимое artifacts, которое должно попасть в файл. Один заголовок artifact не означает, что в DOM присутствует всё содержимое.

Сравните предпросмотр с разговором. Если ответ или artifact отсутствует, вернитесь в Claude, раскройте его и повторите захват.

## Выберите визуальный или редактируемый режим

Визуальный режим сохраняет ритм сообщений, цвета кода и layout. Редактируемый переносит поддерживаемые заголовки, Markdown, списки, код, изображения и ссылки. Сложные artifacts могут остаться визуальными.

[Хаб экспорта AI-чатов](/ru/blog/export-ai-chats-privately) объясняет границу приватности и отличие от архива аккаунта.

## Сравните с экспортом Claude

[Официальная инструкция Anthropic](https://support.claude.com/en/articles/9450526-export-your-claude-data) описывает экспорт данных аккаунта с разговорами и пользовательской информацией для подходящих аккаунтов. Ссылка на архив доставляется отдельно.

Официальный экспорт подходит для backup. Page 2 File нужен, когда результатом должен стать один проверенный PDF в видимом порядке чтения.

## Проверьте конфиденциальный контекст

Разговоры Claude могут содержать клиентские материалы, код и загруженные документы. Удалите постороннее, сохраните нужные источники и соблюдайте правила передачи.

Закрытие предпросмотра Page 2 File удаляет временные данные. Page 2 File не ведёт базу истории и не связан с Anthropic.

## Связанные руководства

Смотрите отдельные инструкции для [ChatGPT](/ru/blog/export-chatgpt-conversation-to-pdf), [Gemini](/ru/blog/export-gemini-chat-to-pdf) и [других AI-ассистентов](/ru/blog/export-other-ai-chats-to-pdf).

## Определите видимую запись Claude

Проверьте conversation, account и workspace. Задайте первое и последнее сообщение, удалите unrelated prompts и drafts. Если ответ зависит от материала вне диапазона, добавьте контекст или отметьте пропуск.

Claude может показывать long responses, code, tables и artifacts рядом с чатом. Откройте нужный view. Artifact в side panel может потребовать visual section; не называйте его исходным attachment, если захвачен только displayed state.

Для edited или retried response зафиксируйте видимый путь. Page 2 File не восстанавливает скрытые alternatives.

## Проверьте citations и attachments

Раскройте sources и протестируйте важные destinations. Оставьте label и контекст ссылки. Экспорт не подтверждает фактическую точность ответа.

Uploads, generated files и images проверяйте отдельно. Чат может упомянуть файл, не показывая его полное содержимое. Wide code и tables оцените при нормальном zoom.

Editable mode подходит поддерживаемому тексту, visual — композиции Claude и сложным элементам.

## Завершите privacy review

Ищите names, credentials, customer data, internal instructions и workspace identifiers. Проверьте sidebars и account controls.

Закройте preview после скачивания. Page 2 File удалит временные данные и не хранит conversion history; копии на вашем устройстве остаются.

Опишите файл как одну видимую беседу Claude на дату. Official data export Anthropic решает более широкую задачу. Page 2 File независим от Anthropic.

## Сверьте PDF с видимым thread

Запишите первый prompt, последний нужный response и обязательные artifacts, code или citations. Сравните их с preview по порядку. Если при открытии позднего материала ранний исчезает, используйте несколько подписанных диапазонов.

## Отдельно проверьте artifacts

Artifact может находиться рядом с transcript и не иметь естественного места в линейном PDF. Решите, нужен ли сам artifact, сообщение, которое его ввело, или оба элемента. При важном layout сохраните его отдельной visual section и обозначьте связь с беседой.

Не называйте отображаемый artifact самостоятельным attachment, если исходный файл не был включён разрешённым способом. Проверьте labels, code и tables при обычном zoom и запишите interactions, которые статичный файл не сохраняет.

Preview удаляется после закрытия вкладки, истории конвертаций нет. Храните утверждённый PDF и scope note самостоятельно.
