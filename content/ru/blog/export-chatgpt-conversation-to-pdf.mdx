## Подготовьте разговор

Прокрутите к началу нужного диапазона и дождитесь старых сообщений. Раскройте код, таблицы, источники и свёрнутые ответы. По возможности закройте посторонние панели.

Если длинный чат виртуализирует сообщения, проверьте, остаётся ли ранний контент в отрисованной странице. Предпросмотр показывает, что получил Page 2 File.

## Выберите вид документа

Accurate copy — режим точной визуальной копии сохраняет карточки сообщений, интервалы и оформление кода. Editable document — режим редактируемого документа переносит поддерживаемые текст, код, таблицы, изображения и ссылки в более чистый документ, заменяя сложные элементы изображениями.

Общее [руководство по приватности AI-чатов](/ru/blog/export-ai-chats-privately) объясняет различия и временную границу предпросмотра.

## Проверьте приватность и источники

Удалите secrets, персональные данные и посторонние prompts до передачи. Сохраняйте видимые citations и URL, когда они нужны для понимания ответа, но проверяйте утверждения независимо.

Закрытие предпросмотра удаляет временные данные; база истории Page 2 File не создаётся. Page 2 File — независимый продукт, не связанный и не одобренный OpenAI.

## Определите точный thread

Проверьте conversation, account и workspace. Для альтернативных branches выберите нужный путь: Page 2 File записывает видимый вариант и не объединяет скрытые ответы.

Задайте первое и последнее message. Сохраните prompt, который объясняет задачу, нужные ответы и citations; удалите личные и посторонние эксперименты.

В shared GPT и workspace учитывайте правила распространения. Доступ к thread не означает право передавать его наружу.

## Обработайте код, таблицы и источники

Раскройте code blocks и проверьте широкие строки. Accurate copy сохраняет styling, editable удобнее для копирования текста. Wide tables могут потребовать отдельной секции.

Generated images и file summaries проверяйте отдельно: PDF беседы не обязательно включает исходный attachment.

## Проверьте PDF

Прочитайте файл от первого prompt до последнего ответа. Проверьте order, speakers, code indentation, tables, citations и page breaks. Найдите фразы из начала и конца.

Осмотрите account names, email, workspace labels и sidebars. Redaction выполняется до передачи. После скачивания закройте preview: временные данные удалятся, а локальный файл останется у вас.

## Точно обозначьте scope

Назовите результат копией одной видимой беседы ChatGPT на определённую дату. Это не полный account archive, не запись всех branches и не доказательство правильности ответов.

Для общего архива используйте актуальные официальные инструкции OpenAI. Page 2 File независим от OpenAI; упоминание продукта не означает endorsement.

## Проведите финальную сверку thread-to-file

Сопоставьте первый prompt, последний нужный response, code, tables и citations с preview. Убедитесь, что выбрана ожидаемая branch, а исключения записаны.

Откройте PDF в обычном reader, проверьте важную source link, перенос code и поиск текста в Editable document. Закрытие preview удаляет временные данные. Храните файл и capture date по тем же правилам доступа, что и исходные prompts и uploads.
