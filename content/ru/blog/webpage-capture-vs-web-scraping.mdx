Захват веб-страницы сохраняет один показанный документ для чтения или подтверждения. Сбор данных извлекает одинаковые поля, часто со множества адресов, для анализа. Page 2 PDF выполняет первую задачу в активной вкладке Chrome и не является обходчиком, API или системой массовой выгрузки.

## Используйте PDF для читаемой фиксации

PDF подходит, когда другой человек должен посмотреть страницу как документ. Accurate copy передаёт внешний вид изображениями. Editable document может сохранить обычный текст, безопасные ссылки и часть полей формы. Оба способа начинают работу с уже открытой вкладки.

Так фиксируют закрытый отчёт, исследовательскую статью, чек, состояние панели управления или текущую переписку. Расширение обрабатывает одну страницу, даже если она очень длинная. Оно не переходит по ссылкам, не находит соседние разделы и не объединяет сайт автоматически.

## Выбирайте API или выгрузку для набора записей

Штатный экспорт, API или разрешённый сборщик нужен, когда результатом должны стать строки и поля: цены со многих карточек, все счета аккаунта, каталог или регулярное наблюдение. Такая работа требует пагинации, удаления дублей, контроля частоты, схемы данных и правил доступа — этого в Page 2 PDF нет.

Выделяемый текст в PDF не равен структурированной таблице. Документ сохраняет порядок чтения, но не гарантирует одинаковые колонки для анализа. Визуальный файл состоит из изображений и подходит для извлечения ещё меньше.

## Авторизация не расширяет назначение

Page 2 PDF может сохранить страницу, которую вы уже вправе смотреть, поскольку работает в активной вкладке. Это не даёт права собирать весь аккаунт, обходить ограничения или автоматизировать навигацию. Условия сайта, конфиденциальность, авторское право и правила организации продолжают действовать.

Для диаграмм и таблиц — [руководство по панелям управления](/ru/blog/save-dashboard-report-to-pdf). Запуск расширения описан на странице [как пользоваться Page 2 PDF](/ru/chrome-extension/how-to-use).

## Совмещайте методы с чёткой границей

Разрешённая аналитическая работа может использовать API для расчётов и PDF как читаемое подтверждение отдельного решения. Сохраните идентификаторы, связывающие запись с исходной страницей или набором данных, и дату получения. Не считайте PDF доказательством полноты собранного набора.

И наоборот, большая длина страницы сама по себе не требует обходчика. Если нужно сохранить один текущий отчёт, это всё ещё захват. Различие определяется целью и масштабом результата, а не количеством экранов.

## Вопросы о двух подходах

### Можно передать список URL?

Нет. Page 2 PDF работает с текущей вкладкой и не обрабатывает адреса пакетом.

### ZIP проекта содержит набор данных страницы?

Нет. Необязательный очищенный архив предназначен для подтверждения и диагностики. Это не формат извлечения и не файл для обратного импорта.

### Как сохранить всю документацию сайта?

Используйте официальный офлайн-пакет, репозиторий, экспорт документации или разрешённый обходчик. PDF создавайте для отдельных страниц, которые нужно читать и подтверждать.
