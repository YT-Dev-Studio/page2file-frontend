Page 2 PDF работает с закрытой страницей и разрешённым локальным HTML, потому что получает содержимое из активной вкладки Chrome. Расширение не принимает пароль, не открывает закрытый адрес вместо пользователя и не снимает ограничения доступа. Нужная страница должна уже отображаться у вас.

## Сохраните страницу после обычного входа

Авторизуйтесь средствами самого сайта, откройте точный отчёт или документ и проверьте выбранные данные. Запустите Page 2 PDF из этой вкладки. Для фиксации экранного вида используйте Accurate copy; для выделяемого текста и безопасных ссылок — Editable document.

Такой подход отличается от серверного конвертера. Вставленный адрес не содержит состояние вашей сессии, а передача авторизационных данных внешнему сервису означала бы другую модель безопасности. Page 2 PDF читает уже показанную вкладку в рамках разрешений расширения и формирует файл внутри его рабочего процесса.

## Откройте локальный HTML в Chrome

Перетащите разрешённый файл `.html` в браузер или воспользуйтесь командой открытия файла. В настройках расширения Chrome может потребоваться включить доступ к файловым адресам. Это разрешение относится к страницам, которые Chrome показывает из локального файла, и не означает чтение любых данных на компьютере.

Проверьте относительные изображения, шрифты и таблицы стилей. Локальный документ может ссылаться на отсутствующие файлы или ожидать ресурсы веб-сервера. Расширение не воссоздаст то, что Chrome не загрузил. Для точного вида выберите Accurate copy, для работы с текстом — Editable document. Основные требования собраны в [инструкции Page 2 PDF](/ru/chrome-extension/how-to-use).

## Отдельно оцените право на сохранение

Подготовка в браузере не отменяет правила владельца сайта, работодателя, клиента или участников переписки. Убедитесь, что вы вправе создавать и передавать документ. Не используйте расширение для обхода доступа, срока хранения или запрета на распространение.

Не закрывайте исходную вкладку. Если сайт завершит сессию, обновит отчёт, удалит временный файл или спрячет данные в защищённом фрейме, PDF может оказаться неполным. Перед передачей просмотрите все страницы. Для отчётов с широкими таблицами и вложенными областями продолжите с [руководством по панелям управления](/ru/blog/save-dashboard-report-to-pdf).

Если закрытая страница содержит подтверждение покупки, перед сохранением используйте [проверку чека и заказа](/ru/blog/save-receipt-order-page-to-pdf).

## Какие страницы Chrome недоступны

Браузер запрещает расширениям работу на своих настройках, в Chrome Web Store, инструментах разработчика, режиме просмотра кода страницы и других защищённых разделах. Обычные вкладки `http:`, `https:` и разрешённые `file:` можно экспортировать.

Если действие на странице заблокировано браузером, выбор другого режима не снимет этот запрет. Используйте функцию скачивания или печати самой страницы.

## Вопросы о доступе

### Расширение сохраняет пароль от сайта?

Нет. Вход остаётся между Chrome и исходным сайтом. Page 2 PDF не запрашивает учётные данные.

### Можно вставить адрес внутреннего сайта на Page 2 File?

Не для этого способа. Сначала откройте внутреннюю страницу в Chrome, затем запустите расширение.

### Локальный HTML станет редактируемым проектом?

Нет. Необязательный очищенный ZIP может содержать PDF, сведения о захвате, снимок MHTML и контрольные суммы. Обратный импорт и редактирование из него не поддерживаются.
