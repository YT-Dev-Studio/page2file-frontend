To save a receipt, booking, invoice, or order-confirmation page, open the completed transaction record in Chrome and export that one active tab. Use Accurate copy when visual layout is important; use Editable document when order numbers, dates, totals, and support links should remain searchable.

## Confirm the record before capture

Check the merchant or provider name, transaction date, currency, total, tax, item list, booking details, and status. Wait for the final confirmation state rather than saving a payment form or loading screen. Expand line items only when they belong in the record.

Remove unrelated navigation or account panels through the site's own controls when possible. Page 2 PDF does not offer arbitrary region clipping, so it preserves the prepared page rather than a hand-drawn rectangle. If the service provides an official invoice or receipt download, prefer that file for accounting and use the page PDF only when it adds needed context.

## Choose visual or searchable evidence

Accurate copy preserves the rendered card, branding, layout, and status indicators as image pages. That can help when appearance is part of the record, but text will not be selectable and links will not work.

Editable document uses Chromium PDF output. It can keep page text and safe support or tracking links. **As viewed** follows the screen state, while **Print optimized** uses the provider's print stylesheet. Review the print version carefully because a site may hide navigation well but also omit an on-screen status or note.

The [PDF mode comparison](/en/blog/choose-webpage-pdf-mode) provides a quick selection rule. The [private-page guide](/en/blog/save-private-or-local-page-to-pdf) covers signed-in account pages. The [webpage-to-PDF product page](/en/chrome-extension/webpage-to-pdf) explains the two webpage outputs.

## Protect payment and personal data

A receipt can contain a name, address, partial payment details, booking reference, loyalty number, or access link. Exclude information the recipient does not need and store the PDF according to the same policy as the original account record. Supported form handling intentionally excludes password, file, hidden, and sensitive controls, but that does not sanitize all visible text.

Page 2 PDF does not export an account's full order history. Filter or navigate to each record and save it separately, or use the provider's account-data or invoice export. The tab being exported must remain open until preparation completes.

## Check the finished file

Compare the amount, currency, date, order number, page count, and status with the original page. Test important links in Editable document. Look for clipped item rows, missing QR codes, unloaded images, or headers repeated over line items.

If the confirmation appears inside an internally scrolling panel, use the [long-page workflow](/en/blog/save-long-dynamic-webpage-to-pdf). For a table-heavy account report, the [dashboard guide](/en/blog/save-dashboard-report-to-pdf) is more appropriate.

## Receipt questions

### Can the extension download every invoice in my account?

No. It works with one active tab and does not perform account-wide or bulk export.

### Will a QR code remain usable?

It can appear in visual output if the page renders it, but scan it from the finished PDF before relying on it. Expiring or protected codes may stop working independently of the PDF.

### Is the saved page an official invoice?

Not automatically. Legal and accounting status comes from the issuer and applicable rules. Use the issuer's official document when one is provided.
