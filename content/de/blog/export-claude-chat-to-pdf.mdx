## Wählen Sie Seitenaufnahme oder bearbeitbaren Modus

Accurate copy (Ausgabe im Stil einer Seitenaufnahme) bewahrt Nachrichtenrhythmus, Codefarben und Layout. Editable document (bearbeitbare Ausgabe) baut unterstützte Überschriften, Markdown, Listen, Code, Bilder und Links für Suche und Wiederverwendung neu auf. Komplexe Artefaktansichten können Seitenaufnahmen bleiben.

Die [Übersicht zum KI-Chat-Export](/de/blog/export-ai-chats-privately) erläutert Datenschutzgrenze und Unterschied zum Kontoarchiv.

## Vergleichen Sie mit dem Claude-Datenexport

Die [offiziellen Exportanweisungen](https://support.claude.com/en/articles/9450526-export-your-claude-data) von Anthropic beschreiben einen Kontodatenexport, der bei berechtigten Nutzern Unterhaltungen und Nutzerdaten enthält. Der Link zum verarbeiteten Download wird getrennt zugestellt.

Verwenden Sie den offiziellen Export für die Kontosicherung. Verwenden Sie Page 2 File, wenn das Ergebnis ein geprüftes PDF in sichtbarer Lesereihenfolge sein soll.

## Prüfen Sie vertraulichen Kontext

Claude-Chats können Kundenmaterial, Code und hochgeladene Dokumente enthalten. Entfernen Sie nicht zugehörige Inhalte, bewahren Sie notwendige Quellenangaben und befolgen Sie geltende Freigaberegeln.

## Prüfen Sie Quellenangaben und Anhänge

Öffnen Sie Quellen und testen Sie wichtige Ziele nach der Konvertierung. Bewahren Sie genug Beschriftung und Umgebungstext, um den Grund des Links zu erklären. Eine Quelle kann sich später ändern, und ihr Export bestätigt nicht die sachliche Richtigkeit der Antwort.

Prüfen Sie hochgeladene Inhalte, erzeugte Dateien und Bilder getrennt. Die Unterhaltung kann eine Datei erwähnen, ohne deren vollständigen Inhalt in die Seite einzubetten. Nennen Sie diese Einschränkung, statt zu behaupten, das PDF enthalte den Originalanhang.

Breiter Code und Tabellen benötigen eine Lesbarkeitsprüfung bei Normalzoom. Verwenden Sie Editable document, wenn unterstützter Text kopiert werden muss, oder Accurate copy, wenn Claudes dargestellte Komposition der primäre Datensatz ist.

## Schließen Sie eine Datenschutz- und Umfangsprüfung ab

Durchsuchen Sie die Vorschau nach Namen, Zugangsdaten, Kundeninformationen, internen Anweisungen und Workspace-Kennungen. Prüfen Sie Seitenleisten und Kontosteuerungen, die in den erfassten Bereich gelangt sein könnten. Entfernen Sie Daten, die Empfänger nicht benötigen.

Schließen Sie nach dem Download die Vorschau, um temporäre Daten zu löschen. Schützen Sie das lokale PDF passend zum Inhalt der Unterhaltung. Page 2 File speichert keinen Konvertierungsverlauf, kann aber Kopien auf Ihrem Gerät oder im gemeinsamen Speicher nicht entfernen.

Kennzeichnen Sie das Ergebnis als eine an einem Datum erfasste sichtbare Claude-Unterhaltung. Anthrophics offizieller Datenexport dient einem umfassenderen Kontodatendienst. Page 2 File ist unabhängig von Anthropic und zertifiziert keine Modellausgabe.

## Entscheiden Sie, wie Artefakte dargestellt werden

Ein Artefakt kann neben der Hauptunterhaltung erscheinen und passt möglicherweise nicht natürlich in die Transkriptreihenfolge. Entscheiden Sie, ob Leser das Artefakt, die einführende Nachricht oder beides benötigen. Erfassen Sie seinen sichtbaren Zustand als getrennten Aufnahmeabschnitt, wenn das Layout wichtig ist, und kennzeichnen Sie seine Position in der Unterhaltung.

Bezeichnen Sie ein dargestelltes Artefakt nicht als unabhängig angehängte Quelldatei, sofern diese Datei nicht über einen autorisierten Ablauf enthalten wurde. Prüfen Sie kleine Beschriftungen, Code und Tabellen bei Normalzoom und notieren Sie Interaktionen oder Versionsverläufe, die ein statisches Dokument nicht bewahren kann.

Halten Sie spätere Änderungen von der freigegebenen Erfassung getrennt.
