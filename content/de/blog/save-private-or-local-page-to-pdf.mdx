Page 2 PDF kann eine angemeldete Webseite oder eine erlaubte lokale HTML-Datei verarbeiten, weil die Erweiterung mit dem aktiven Chrome-Tab arbeitet. Sie nimmt keine Zugangsdaten entgegen, öffnet keine private URL für Sie und umgeht keine Zugriffssperre; die gewünschte Seite muss bereits sichtbar sein.

## Speichern Sie eine Seite nach der Anmeldung

Melden Sie sich über die normale Website an, öffnen Sie den gewünschten Bericht oder Beleg und prüfen Sie Werte, Filter und Zeitraum. Starten Sie Page 2 PDF anschließend genau in diesem Tab. Accurate copy eignet sich, wenn der sichtbare Zustand zählt; Editable document ist sinnvoller für durchsuchbaren Text und sichere anklickbare Links.

Das unterscheidet sich von einem serverseitigen URL-Konverter. Eine eingefügte Adresse enthält nicht Ihre angemeldete Browser-Sitzung. Page 2 PDF liest stattdessen den geöffneten Tab über die Berechtigungen der Erweiterung. Der Vergleich [URL zu PDF oder Drucken als PDF](/de/blog/url-to-pdf-vs-print-to-pdf) ordnet die drei Eingabemethoden ein.

## Öffnen Sie lokale HTML-Dateien bewusst

Ziehen Sie eine erlaubte `.html`-Datei in Chrome oder verwenden Sie „Datei öffnen“. In den Erweiterungseinstellungen kann **Zugriff auf Datei-URLs zulassen** nötig sein. Diese Berechtigung betrifft lokale Seiten, die Chrome im Tab bereitstellt; sie ist kein allgemeiner Zugriff auf beliebige Dateien.

Prüfen Sie nach dem Laden relative Bilder, Schriften und Stylesheets. Lokales HTML kann auf fehlende Dateien oder Adressen eines Webservers verweisen. Solche Ressourcen kann die Erweiterung nicht rekonstruieren. Speichern Sie die geladene Darstellung mit Accurate copy oder den auswählbaren Inhalt mit Editable document. Die [Produktseite für HTML zu PDF](/de/chrome-extension/html-page-to-pdf) beschreibt die Voraussetzungen.

## Behandeln Sie vertrauliche Inhalte als Berechtigungsfrage

Die Verarbeitung im Erweiterungsablauf hebt Pflichten gegenüber Arbeitgebern, Kunden, Seitenbetreibern oder Gesprächsteilnehmern nicht auf. Klären Sie, ob Sie eine PDF erstellen, aufbewahren und weitergeben dürfen. Die Erweiterung ist kein Mittel, um Zugriffskontrollen oder Aufbewahrungsregeln zu umgehen.

Lassen Sie den Tab während der Vorbereitung offen. Wenn die Sitzung abläuft, der Bericht seinen Zustand ändert oder ein geschützter Frame Daten zurückhält, kann das Ergebnis unvollständig sein. Prüfen Sie jede Seite vor dem Versand. Bei breiten Tabellen folgt danach der [Dashboard-Leitfaden](/de/blog/save-dashboard-report-to-pdf); für Kaufbestätigungen gibt es die [Checkliste für Belege](/de/blog/save-receipt-order-page-to-pdf).

Chrome sperrt Erweiterungen unter anderem auf Einstellungsseiten, im Chrome Web Store, in Entwicklertools und im Quelltextbetrachter. Ein anderer Page-2-PDF-Modus hebt diese Browsersperre nicht auf; verwenden Sie dort die eingebaute Download- oder Druckfunktion.

## Fragen zu Zugriff und Dateien

### Speichert Page 2 PDF mein Website-Passwort?

Nein. Die Anmeldung bleibt zwischen Chrome und der Originalwebsite. Die Erweiterung fragt keine Zugangsdaten ab, sondern verarbeitet die bereits gerenderte Seite.

### Kann ich eine Intranet-URL einfügen?

Nicht in diesem Ablauf. Öffnen Sie die Intranetseite in Chrome und starten Sie Page 2 PDF im aktiven Tab.

### Wird lokales HTML zu einem editierbaren Projekt?

Nein. Ein optionales bereinigtes ZIP kann PDF, Metadaten, MHTML-Abbild und Prüfsummen enthalten. Page 2 PDF kann dieses Archiv nicht wieder importieren oder als Website-Editor öffnen.
