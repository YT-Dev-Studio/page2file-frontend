Prüfen Sie vor dem Download erfassten Bereich, Seitenumbrüche, Codeblöcke und Links.

Dadurch entsteht ein lesbares Dokument aus einer sichtbaren Unterhaltung. Es entspricht nicht dem Konto-Datenexport von OpenAI und rekonstruiert keine verborgenen oder nicht geladenen Zweige.

## Bereiten Sie die Unterhaltung vor

Scrollen Sie zum Anfang des benötigten Bereichs und warten Sie, bis ältere Nachrichten erscheinen. Öffnen Sie Code, Tabellen, Quellen und eingeklappte Antworten, die in das PDF gehören. Schließen Sie möglichst nicht zugehörige Seitenbereiche.

Virtualisiert ein langer Chat Nachrichten, prüfen Sie, ob frühere Inhalte in der gerenderten Seite bleiben. Die Vorschau belegt, was Page 2 File erhalten hat.

## Wählen Sie den Dokumentstil

Accurate copy (Ausgabe im Stil einer Seitenaufnahme) erhält Nachrichtenkarten, Abstände und Codestil der Unterhaltung. Editable document (bearbeitbare Ausgabe) überträgt unterstützten Text, Code, Tabellen, Bilder und Links in ein klareres Dokument; komplexe Elemente werden als Bilder dargestellt.

Der allgemeine [Datenschutzleitfaden für KI-Chats](/de/blog/export-ai-chats-privately) erläutert den Unterschied und die Grenze der temporären Vorschau.

## Erkennen Sie, wann der OpenAI-Export geeignet ist

Der [offizielle Datenexport](https://help.openai.com/en/articles/7260999-how-do-i-export-my-chatgpt-history-and-data) von OpenAI kann Chatverlauf und weitere Kontodaten in einer ZIP-Datei enthalten. Er eignet sich für Sicherungen und Datenauskunftsanfragen statt für ein gestaltetes PDF eines Threads.

Verwenden Sie Page 2 File für eine ausgewählte lesbare Unterhaltung. Verwenden Sie den offiziellen Export für das umfassendere Archiv, wenn Konto- oder Workspace-Anforderungen erfüllt sind.

## Prüfen Sie Privatsphäre und Quellenangaben

Entfernen Sie Geheimnisse, personenbezogene Daten und nicht zugehörige Prompts vor der Weitergabe. Bewahren Sie sichtbare Quellenangaben und URLs, wenn sie zum Verständnis notwendig sind, prüfen Sie Aussagen aber unabhängig.

Das Schließen der Vorschau löscht temporäre Daten; es wird keine Page 2 File Datenbank mit dem Konvertierungsverlauf angelegt. Page 2 File ist unabhängig und weder mit OpenAI verbunden noch von OpenAI empfohlen.

## Fahren Sie mit verwandten Chats fort

Verwenden Sie für andere Assistenten den Leitfaden zu [Claude](/de/blog/export-claude-chat-to-pdf), [Gemini](/de/blog/export-gemini-chat-to-pdf) oder [anderen KI-Chats](/de/blog/export-other-ai-chats-to-pdf). Jede Quelle muss in ihrem eigenen Browser-Tab geladen werden.

## Definieren Sie den exakten Thread

Bestätigen Sie vor der Erfassung Unterhaltungstitel und Konto oder Workspace. Hat der Chat alternative Zweige, wählen Sie den Pfad, der ins Dokument gehört. Page 2 File zeichnet den sichtbaren Pfad auf und führt verborgene Alternativen nicht zu einem Transkript zusammen.

## Behandeln Sie Code, Tabellen und Quellen

Öffnen Sie Codeblöcke und prüfen Sie die Lesbarkeit horizontaler Inhalte. Accurate copy bewahrt den dargestellten Stil, Editable document eignet sich besser zum Kopieren unterstützten Texts. Sehr breite Tabellen oder lange Zeilen benötigen möglicherweise einen eigenen Abschnitt oder Bild-Fallback.

Öffnen Sie Quellenbereiche und Listen, die zur Interpretation erforderlich sind. Testen Sie einige Links im PDF und entfernen Sie private oder temporäre Ziele. Eine verlinkte Quelle kann sich ändern, und ihr Vorhandensein beweist keine Modellaussage.

Erzeugte Bilder und Zusammenfassungen angehängter Dateien benötigen eine getrennte Prüfung. Bestätigen Sie, dass das im Chat gezeigte Material aufbewahrt werden darf, und notieren Sie, wenn der zugrunde liegende Anhang nicht im PDF enthalten ist.

## Prüfen Sie die exportierte Unterhaltung

Lesen Sie das PDF vom ersten Prompt bis zur letzten enthaltenen Antwort. Prüfen Sie Nachrichtenreihenfolge, Sprecherunterscheidung, Codeeinrückung, Tabellen, Quellenangaben und Seitenumbrüche. Suchen Sie nach einem Ausdruck vom Anfang und Ende, um den vorgesehenen Bereich zu bestätigen.

Prüfen Sie Kontonamen, E-Mail-Adressen, Workspace-Bezeichnungen und Seitenleisten. Wird die Datei geteilt, ist Schwärzung Teil des Exportablaufs und kein optionaler Schritt nach der Lieferung.

Schließen Sie nach Prüfung und Download die Vorschau. Temporäre Daten werden gelöscht, und Page 2 File führt keine Konvertierungsverlaufsdatenbank; die heruntergeladene Datei bleibt unter Ihrer Kontrolle.

## Geben Sie den Umfang korrekt an

Kennzeichnen Sie die Datei als Kopie einer sichtbaren ChatGPT-Unterhaltung, die an einem bestimmten Datum erfasst wurde. Bezeichnen Sie sie weder als vollständiges Kontoarchiv noch als verifiziertes Transkript aller Zweige oder Beweis für die Richtigkeit der Antworten.

Folgen Sie für eine Sicherung auf Kontoebene den aktuellen offiziellen Exportanweisungen von OpenAI und prüfen Sie das bereitgestellte Archiv. Beide Abläufe können nebeneinander bestehen, weil sie unterschiedliche Aufgaben lösen.

Page 2 File ist unabhängig von OpenAI. Produktnamen bezeichnen die Quelloberfläche und bedeuten keine Förderung, Empfehlung oder privilegierten Zugriff.

## Führen Sie eine abschließende Thread-zu-Datei-Prüfung durch

Gleichen Sie ersten Prompt, letzte erforderliche Antwort und jeden wichtigen Codeblock, jede Tabelle oder Quellenangabe mit der Vorschau ab. Prüfen Sie, ob der sichtbare Antwortzweig den Erwartungen des Lesers entspricht, und erfassen Sie bewusst ausgeschlossene Zweige oder Nachrichten.

Öffnen Sie das heruntergeladene PDF in einem gewöhnlichen Reader. Testen Sie einen wichtigen Quellenlink, prüfen Sie Codeumbrüche und suchen Sie bei bearbeitbarer Ausgabe nach repräsentativem Text. Das Schließen des Vorschau-Tabs löscht temporäre Daten; das freigegebene PDF bleibt anschließend unter Ihrer Kontrolle.
