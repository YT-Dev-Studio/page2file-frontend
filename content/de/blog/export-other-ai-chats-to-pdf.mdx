Öffnen Sie eine Unterhaltung, laden Sie ihre sichtbaren Quellen und erfassen Sie sie mit der [Page 2 File Erweiterung](/de/chrome-extension/how-to-use).

Page 2 File verwendet eine konservative Browserseitengrenze. Es behauptet keinen Zugriff auf verborgene Threads, Modellspeicher, Kontoarchive oder native Anwendungen.

## Bereiten Sie jede Plattform nach ihrer Darstellung vor

Grok und Perplexity zeigen häufig Quellenlinks oder Karten. Copilot kann Unterhaltungen mit Webergebnissen oder Microsoft-Inhalten mischen. DeepSeek kann lange analysierende Antworten und Code enthalten. Öffnen Sie nur die für den Datensatz benötigten Blöcke.

Scrollen Sie zum Laden des vollständigen erforderlichen Bereichs und vergleichen Sie anschließend Quell-Tab und Vorschau. Eine fehlende Nachricht bedeutet, dass die Seite sie für die Erfassung nicht bereitgestellt hat.

## Halten Sie Quellenangaben nutzbar

Bearbeitbare Ausgabe kann unterstützte sichtbare Links bewahren, wenn ihre Ziele sicher sind. Accurate copy (Ausgabe im Stil einer Seitenaufnahme) erhält das Kartenlayout, kann Linkbeschriftungen aber zu Pixeln machen, sofern keine Overlays verfügbar sind.

Prüfen Sie wichtige Aussagen an der verlinkten Quelle. Die Erfassung einer KI-Antwort validiert sie nicht.

## Wählen Sie den Ausgabemodus

Wählen Sie Accurate copy für das ursprüngliche Unterhaltungs- und Quellenkartenlayout. Wählen Sie Editable document (bearbeitbare Ausgabe), wenn durchsuchbarer Text, Code und wiederverwendbare Links wichtig sind. Komplexe Widgets können Bilder bleiben.

Die [Übersicht zum KI-Chat-Export](/de/blog/export-ai-chats-privately) erläutert Datenschutz und Unterschiede zum Kontoarchiv. Vergleichen Sie plattformspezifische Schritte in den Leitfäden zu [ChatGPT](/de/blog/export-chatgpt-conversation-to-pdf) und [Claude](/de/blog/export-claude-chat-to-pdf).

## Wenden Sie dieselbe Datenschutzgrenze an

Prüfen Sie Prompts, Uploads, Kontonamen und interne Inhalte vor dem Download. Das Schließen der Vorschau löscht temporäre Daten, und Page 2 File speichert keinen Konvertierungsverlauf.

Page 2 File ist unabhängig und wird weder von xAI, DeepSeek, Perplexity, Microsoft noch den genannten Assistenten empfohlen.

## Passen Sie die Vorbereitung an die Oberfläche an

Grok, DeepSeek, Perplexity und Copilot stellen Unterhaltungen unterschiedlich dar. Ermitteln Sie Hauptnachrichtenspalte, Quellenbereich, Anhangsbereich und Zweig- oder Neuschreibesteuerungen. Laden Sie nur Material, das für das Dokument erforderlich ist.

Einige Oberflächen betonen Quellenangaben, andere platzieren erzeugte Dateien oder Code in einem getrennten Bereich. Öffnen Sie diese Elemente vor der Erfassung und prüfen Sie, ob sie beim Zurückkehren zum Anfang erhalten bleiben. Ein verborgener Bereich gehört nicht zur Ausgabe, nur weil die Antwort auf ihn verweist.

Wählen Sie einen klaren ersten und letzten Turn. Erfassen Sie bei einem langen Thread bekannte Auslassungen, statt ein vollständiges Transkript zu behaupten, das die Vorschau nicht belegt.

## Bewahren Sie Quellenkontext ohne Übertreibung

Behalten Sie sichtbare Quellenbeschriftungen und testen Sie wichtige Links. Quellenkarten im Stil von Perplexity oder Copilot-Referenzen können zum Verständnis wichtig sein, machen aber nicht jede erzeugte Aussage richtig. Die Überprüfung bleibt eine getrennte Aufgabe.

Code, Tabellen und Formeln benötigen eine Lesbarkeitsprüfung bei Normalgröße. Editable document unterstützt die Wiederverwendung erkannten Texts; Accurate copy bewahrt Oberflächenstil. Komplexe Karten, Diagramme und erzeugte Medien können Bild-Fallbacks bleiben.

## Wenden Sie plattformübergreifend einen Datenschutzstandard an

Prüfen Sie Kontonamen, private Prompts, Zugangsdaten, Kundeninformationen und Seitenverlauf. Plattformunterschiede ändern nicht die Pflicht, den Inhalt beim Verlassen des Browsers zu minimieren.

Verwenden Sie offizielle Plattformexporte für Kontoarchive, sofern vorhanden und geeignet. Die Erfassung des aktiven Tabs ist für eine ausgewählte sichtbare Unterhaltung gedacht und kein Ersatz für administrative Aufbewahrungs- oder Compliance-Werkzeuge.

## Prüfen Sie die aktuellen Plattformsteuerungen

Die [Verbraucher-FAQ](https://x.ai/legal/faq) von xAI dokumentiert Verlauf, Freigabe und Datensteuerungen für Grok. Der [offizielle Sitzungsleitfaden](https://www.perplexity.ai/help-center/en/articles/10354769-what-is-a-thread) von Perplexity beschreibt die Browser-Unterhaltungsstruktur und native Exportoptionen. Microsoft dokumentiert den [Copilot-Unterhaltungsverlauf](https://support.microsoft.com/en-us/Microsoft-Copilot/conversation-history-in-microsoft-copilot) und getrennte Exporte über das Datenschutzdashboard.

Öffentliche DeepSeek-Dokumentation muss für die Erfassung des aktiven Tabs nicht dieselben Steuerungen bieten. Prüfen Sie die aktuelle [offizielle Datenschutzrichtlinie](https://chat.deepseek.com/downloads/DeepSeek%20Privacy%20Policy.pdf), die Oberfläche und Ihre Kontoeinstellungen, bevor Sie einen Export entscheiden. Leiten Sie keine native Archivfunktion aus der Dokumentation eines anderen Assistenten ab.

Plattformsteuerungen können sich ändern. Folgen Sie für native Exporte oder Kontodatenanfragen der aktuellen offiziellen Seite und verwenden Sie Page 2 File nur für den autorisierten Unterhaltungszustand, der in Chrome gerendert ist.

## Gleichen Sie jeweils einen Chat ab

Markieren Sie erste und letzte erforderliche Nachricht und listen Sie Quellenangaben, erzeugte Medien, Code, Anhänge oder Seitenbereiche auf, die Bedeutung tragen. Vergleichen Sie diese Punkte mit der Vorschau. Verschwinden ältere Inhalte beim Scrollen, verwenden Sie kleinere gekennzeichnete Bereiche und erfassen Sie die Lücke.

Prüfen Sie bei Accurate copy Sendergruppierung, Quellenkarten und kleine Oberflächenbeschriftungen. Suchen Sie bei Editable document repräsentative Ausdrücke, testen Sie wichtige Ziele und kennzeichnen Sie Raster-Fallbacks. Eine Quellenbeschriftung beweist keine erzeugte Aussage; prüfen Sie folgenreiche Quellen unabhängig.

Öffnen Sie das endgültige PDF außerhalb der Vorschau und prüfen Sie Lesbarkeit und Seitengrenzen bei Normalzoom. Nennen Sie Assistent, sichtbaren Bereich, Erfassungsdatum und bekannte Auslassungen in der Übergabe.

## Halten Sie Produkt- und Plattformdatenschutz getrennt

Die Page 2 File Erweiterung arbeitet mit dem aktiven Tab. Vorschaudaten sind temporär, werden beim Schließen des Vorschau-Tabs gelöscht und nicht in einer Konvertierungsverlaufsdatenbank aufbewahrt. Diese Fakten beschreiben nicht, wie Grok, DeepSeek, Perplexity oder Copilot die ursprüngliche Unterhaltung speichern.

Prüfen Sie die aktuellen Einstellungen und Richtlinien jeder Plattform für Aufbewahrung, Freigabe und Kontoexporte. Nach dem Download bleibt das PDF auf Ihrem Gerät oder gewählten Speicher. Entfernen Sie Zugangsdaten, private Prompts, Kontokennungen und signierte Links vor der Verteilung.
