Revise el intervalo capturado, los saltos de página, bloques de código y enlaces antes de descargar.

Esto crea un documento legible a partir de una conversación visible. No equivale a la exportación de datos de OpenAI a nivel de cuenta ni reconstruye ramas ocultas o no cargadas.

## Prepare la conversación

Desplácese hasta el inicio del intervalo requerido y espere a que aparezcan los mensajes anteriores. Expanda código, tablas, fuentes y respuestas contraídas que deban incluirse en el PDF. Cierre los paneles laterales no relacionados cuando sea posible.

Si un chat largo virtualiza mensajes, compruebe que el contenido anterior siga en la página renderizada. La vista previa demuestra lo que recibió Page 2 File.

## Elija el estilo del documento

Accurate copy (salida como capturas) conserva las tarjetas de mensajes, el espaciado y el estilo del código de la conversación. Editable document (salida editable) asigna texto, código, tablas, imágenes y enlaces compatibles a un documento más limpio, usando imágenes como alternativa para elementos complejos.

La [guía general de privacidad para chats de IA](/es/blog/export-ai-chats-privately) explica la diferencia y el límite temporal de la vista previa.

## Sepa cuándo usar la exportación de OpenAI

La [exportación oficial de datos](https://help.openai.com/en/articles/7260999-how-do-i-export-my-chatgpt-history-and-data) de OpenAI puede incluir el historial de chats y otros datos de la cuenta en un ZIP. Es adecuada para copias de seguridad y solicitudes de datos, no para un PDF pulido de un hilo.

Use Page 2 File para una conversación seleccionada y legible. Use la exportación oficial cuando necesite el archivo más amplio y cumpla los requisitos de la cuenta o espacio de trabajo.

## Compruebe privacidad y atribución

Elimine secretos, datos personales y prompts no relacionados antes de compartir. Conserve citas visibles y URL de fuentes cuando sean necesarias para comprender una respuesta, pero verifique las afirmaciones de forma independiente.

Cerrar la vista previa elimina sus datos temporales; no se crea una base de datos de historial de conversiones en Page 2 File. Page 2 File es independiente y no está afiliado ni respaldado por OpenAI.

## Continúe con chats relacionados

Para otro asistente, use la guía de [Claude](/es/blog/export-claude-chat-to-pdf), [Gemini](/es/blog/export-gemini-chat-to-pdf) u [otros chats de IA](/es/blog/export-other-ai-chats-to-pdf). Cada fuente debe cargarse en su propia pestaña del navegador.

## Defina el hilo exacto

Confirme el título de la conversación y la cuenta o espacio de trabajo antes de capturar. Si el chat tiene ramas alternativas, seleccione la ruta que corresponda al documento. Page 2 File registra la ruta visible; no combina alternativas ocultas en una sola transcripción.

## Gestione código, tablas y fuentes

Expanda los bloques de código y verifique que el contenido horizontal sea legible. Accurate copy conserva el estilo mostrado, mientras que Editable document resulta más adecuado para copiar texto compatible. Las tablas muy anchas o líneas largas pueden necesitar su propia sección o una captura alternativa.

Abra los paneles de citas y listas de fuentes necesarios para la interpretación. Pruebe una muestra de enlaces en el PDF y elimine destinos privados o temporales. Una fuente enlazada puede cambiar y su presencia no demuestra la afirmación del modelo.

Las imágenes generadas y resúmenes de archivos adjuntos requieren una revisión independiente. Confirme que se permite conservar el material mostrado en el chat y anote cuando el adjunto subyacente no esté incluido en el PDF.

## Revise la conversación exportada

Lea el PDF desde el prompt inicial hasta la última respuesta incluida. Compruebe el orden de mensajes, la distinción de interlocutores, la sangría del código, tablas, citas y saltos de página. Busque una frase del principio y otra del final para confirmar que el intervalo previsto está presente.

Inspeccione nombres de cuenta, direcciones de correo, etiquetas del espacio de trabajo y contenido de paneles laterales. Si el archivo se va a compartir, la redacción forma parte del flujo de exportación y no es un paso opcional posterior a la entrega.

Cierre la vista previa cuando finalicen la revisión y descarga. Los datos temporales se eliminan y Page 2 File no conserva una base de datos de historial de conversiones; el archivo descargado queda bajo su control.

## Indique el alcance con precisión

Etiquete el archivo como copia de una conversación visible de ChatGPT capturada en una fecha concreta. No la llame archivo completo de la cuenta, transcripción verificada de todas las ramas ni prueba de que las respuestas del modelo sean correctas.

Para una copia de seguridad de la cuenta, siga las instrucciones oficiales actuales de exportación de OpenAI y revise el archivo que proporciona. Ambos flujos pueden coexistir porque resuelven tareas diferentes.

Page 2 File es independiente de OpenAI. Los nombres de productos identifican la interfaz de origen y no implican patrocinio, respaldo ni acceso privilegiado.

## Ejecute una comprobación final del hilo al archivo

Compare con la vista previa el primer prompt, la última respuesta necesaria y cada bloque de código, tabla o cita esencial. Compruebe que la rama visible sea la esperada por el lector y registre las ramas o mensajes excluidos intencionadamente.

Abra el PDF descargado en un lector corriente. Pruebe un enlace de fuente relevante, inspeccione el ajuste del código y busque texto representativo cuando haya seleccionado salida editable. Cerrar la pestaña de vista previa elimina sus datos temporales; el PDF aprobado queda entonces bajo su control.
