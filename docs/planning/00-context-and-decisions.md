# Контекст и подтвержденные решения

## Источник

Полностью прочитан PDF `Продукт - Веб сервис и конвертация.pdf`: 66 страниц сохраненной истории чата. Ниже — нормализованный итог, а не дословная копия.

При конфликте требований применен такой приоритет:

1. Последнее сообщение пользователя.
2. Поздние уточнения в истории.
3. Ранние предложения, только если они не противоречат поздним решениям.

## Подтверждено

### Продукт

- Это единый продукт Page2File с тремя точками входа: веб-сервис, GPTs и Chrome-расширение.
- Веб-сервис работает по публичному URL.
- Конвертация текущей, авторизованной или локальной вкладки — задача расширения.
- Регистрации, аккаунтов и истории конвертаций нет.
- Preview нужен и для PDF, и для PPTX.
- PDF и PPTX имеют два режима:
  - `visual` — секции страницы становятся изображениями; поверх допустимы link annotations;
  - `editable` — текст, ссылки, кнопки, изображения и простые формы создаются нативно, а сложные блоки растрируются.
- Пользователь не выбирает формат внутри формы:
  - PDF имеет отдельную страницу;
  - PowerPoint имеет отдельную страницу;
  - пользователь выбирает только режим.

### Разделение проектов

- Frontend и backend должны быть отдельными проектами и размещаться на разных серверах.
- Next.js отвечает за сайт, SEO, локализацию, блог, legal pages, consent, converter UI, preview UI и тонкий server-side BFF.
- Node.js backend отвечает за URL validation, job orchestration, Chromium, анализ страницы, preview, PDF/PPTX и временные файлы.
- Тяжелая конвертация не должна выполняться внутри Next.js request handler.
- Chrome-расширение — отдельный клиент; его локальный conversion/chat engine не включается в Next.js.

### Страницы

- Главная страница.
- Отдельная welcome-страница расширения.
- Инструкция расширения с переключателем `Step-by-step` / `Video`; текстовая версия остается в HTML.
- Отдельные converter routes для URL → PDF и URL → PPTX.
- GPT landings только для:
  - Page2PDF GPT;
  - Web2PDF GPT;
  - HTML2PDF GPT;
  - Web2PowerPoint GPT.
- AI-chat landings:
  - общий кластер export AI chat to PDF;
  - ChatGPT;
  - Claude;
  - Gemini;
  - Grok.
- Блог хранится в репозитории, максимум 10 статей.
- Updates и changelog.
- Privacy, Terms, Cookie Policy и Security/Acceptable Use.

### Privacy и аналитика

- Постоянного хранения итоговых файлов нет.
- Для серверной URL-конвертации допустима только краткосрочная техническая обработка.
- Preview и итоговый файл удаляются по TTL и после завершения download policy.
- Содержание текущей вкладки и AI-чатов не отправляется на backend.
- Google Analytics подключается только в рамках consent policy.
- UTM поддерживаются, но не становятся пользовательским профилем и не образуют собственную историю.

### Безопасность

- Главная backend-угроза — SSRF, а не только «инъекции».
- Internal conversion/worker endpoints не публикуются для браузера.
- Разные каналы имеют разные политики:
  - web → same-origin Next.js BFF → backend;
  - GPT → отдельные API keys, scopes и quotas;
  - extension → локальная обработка по умолчанию; статический секрет расширения не считается защищенным.
- Нужны schema validation, CSP, CSRF protection, output encoding, SVG/HTML sanitization, sandbox для HTML и запрет shell interpolation.

## Уточненные формулировки

### «Точь в точь и редактируемо»

Нельзя гарантировать для произвольной страницы одновременно:

- пиксельную идентичность;
- полную редактируемость;
- одинаковое поведение HTML/CSS, PDF и PowerPoint.

Контракт продукта:

- `Visual` оптимизирует визуальную точность;
- `Editable & clickable` оптимизирует нативный текст, ссылки и объекты;
- adaptive fidelity растрирует неподдерживаемые элементы или целые сложные блоки;
- preview сообщает о raster fallback и font substitution до скачивания.

### «Ничего не хранится»

Корректный контракт:

- нет аккаунтов и пользовательской истории;
- нет постоянного хранения;
- серверные URL jobs используют короткоживущие metadata/preview/artifacts;
- текущая вкладка и AI-чаты обрабатываются локально расширением.

Нельзя писать, что публичный URL или серверный файл «никогда не касается серверов».

### «Все западные страны»

Язык и страна разделены:

- один качественный язык не дублируется по десяткам стран без реальной региональной разницы;
- locale variants добавляются только при различиях в языке, legal copy, цене или продуктовой информации;
- индексируются только полноценно переведенные и проверенные страницы;
- IP-редиректы для поисковых роботов не используются.

## Не включено в self-hosted MVP

- Выбор конкретного облака и тарифов.
- Публикация GPTs или расширения.
- Исходный код Chrome-расширения.
- Создание юридически окончательных текстов без legal review.
- Внешний pentest и production-grade SLO до fidelity/load spike.

## Статус реализации на 2026-07-30

- Этот репозиторий является самостоятельным Next.js `16.2.12`
  frontend-проектом с 16 locale prefixes.
- Реализованы secure same-origin BFF и real conversion adapter; mock доступен
  только для localhost/test.
- Отдельный sibling `page2file-backend` реализует self-hosted conversion MVP.
- Consent-gated GA4 использует `G-7MVCPE7QMR` и исключает localhost.
- Container/E2E/fidelity/load gates остаются непроверенными до установки Docker
  Desktop; это не переименовывается в production readiness.
